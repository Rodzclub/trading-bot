================================================================================
                        EMERGENCY PROCEDURES
================================================================================

IF BOT CRASHES:
1. Kill the process (Ctrl+C)
2. Check error: tail -20 logs/trading_bot_main.log
3. Document the error
4. Restart: python main.py

IF POSITION WON'T CLOSE:
1. Check dashboard for the position
2. Manually close in Thinkorswim app
3. Wait 30 seconds for bot to sync
4. Continue monitoring

IF LOSING > 2% IN A DAY:
1. BOT WILL AUTO-STOP (Daily limits enforcer)
2. All new trades blocked
3. Monitor existing positions
4. Manual override: Review config_thinkorswim.py MAX_DAILY_LOSS_PCT
